# 方法迭代的保存轨迹

[iteration-case.json](iteration-case.json) 保存本讲既有 east、west、single 现场在 2026-11-15 的运行节选：

- `origin`：原版单告警方法、east 的实际只读查询和原回答
- `candidate`：Hermes 原生后台修订后的同名方法、读写调用投影，以及新会话 west、single 的查询和原回答
- `revision`：审阅代理收紧一条规则后的方法，以及两个后续新会话的查询和原回答

现场来自本讲 [scenario.py](../scenario.py) 的构造数据，模型在保存运行中通过 Hermes 工具取得回执。文件只选取方法正文、业务查询、调用编号、原回答和检查状态；没有包含完整 Session、模型请求或个人环境。`iteration_case.py` 只读这个文件，不重新执行查询、修订或模型任务。

`method_sha256` 是该任务使用的方法主文件指纹；`history_at_start` 和 `loaded_method` 来自任务记录。`checks` 只检查查询和结构化答案，不覆盖全文语义。原回答保留错误与不确定性，不应当作参考答案直接复用。

第一次 east 调查已经成功，不证明原版一定无法处理多告警。候选与后续审阅补丁都只在各自保存的现场观察过；没有原版在同一 west 现场的配对，也没有证明所有任务都得到改善。审阅代理的修订不属于模型自主纠错。你提出的不同补丁需要自己的执行记录，不能借这些结果宣称通过。

重新运行的记录仍进入独立 `runtime/`；保存轨迹与本次运行结果分别展示，不相互补齐。
